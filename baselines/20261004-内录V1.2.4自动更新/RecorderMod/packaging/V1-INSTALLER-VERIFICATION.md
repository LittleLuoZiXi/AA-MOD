## 已确认的行为

- 旧 `0.2.1` 两版可迁移到 `1.0.0`，V1 两版可以互相覆盖。所有已启用本 MOD 的 profile 一并选择 V1；未启用的 profile 不被强行启用。其他 MOD 条目、自定义字段与其他配置档的设置保留。
- 只有原有有效 receipt 中哈希仍一致的旧文件才会清理。用户修改过的旧 DLL、manifest、说明文件，以及没有所有权证明的旧文件保留，profile 不再引用旧版本。
- 设置、教程状态、每日导出序号、剧情、用户视频、开发源码、其他 MOD、外部 FFmpeg 和独立 DLSS 内容在相应安装/卸载中保留。
- receipt 非法、路径越界、重复条目、哈希损坏、无主文件冲突、文件锁定和中途提交失败均会停止；已经发生的文件与 profile 变更可回滚。取消安装确认产生零写入。
- 暂停期间传输停止写入且不发新请求；恢复携带 Range/If-Range。服务器忽略 Range、ETag 改变、错误范围、断连、503/404、损坏摘要均有确定的处理；取消与失败清理本次 `.part`，既有下载文件、其他 `.part` 和并发出现的用户文件不被覆盖。
- DLSS 只安装所选系列与共同组件，使用独立 receipt。修改过的文件不会被修复覆盖；DLSS 卸载不删除内录。
- RTX 20 系在预检阶段允许开始安装，内录本体成功后才提示“暂时不支持20系”并退出 DLSS 阶段，保留已经安装的普通内录，不创建 DLSS 下载临时目录。Intel、其他不支持型号和混合 NVIDIA 系列有明确原因，仍能安装普通内录。
- 支持显卡自动选择 DLSS 阶段，不能用界面跳过必需下载。继续按钮在下载、校验、安装全部完成前禁用；暂停、恢复、取消、重试、关闭和离线失败状态均经过真实窗体检查。完成后表格同步显示已安装，传输文案显示全部完成，网络提示隐藏。
- 安装包不内嵌 DLSS 原生组件。主安装器中包含普通内录 payload 和小型 DLSS 独立卸载器资源；资源哈希与构建证明一致。
- 加壳主 EXE、内录卸载器、DLSS 卸载器均通过 AES/GZip/内存加载的只读 IL 核验；未加壳结构保持可读。四个最终卸载 EXE 都已实际运行成功，删除自身已拥有且未修改的文件并保留用户数据。
- FFmpeg 沿用原有发现、确认和安装规则：无可用版本必须明确确认；已有中文空格路径工具或 PATH 中工具可复用；修改配置只修复对应项。内置二进制实际生成并解码了带 H.264/AAC 的 MP4，校验了尺寸、帧率和时长。

## 测试边界

核心升级夹具使用明确标记的合成 MOD 内容和编码进程桩，只验证安装事务；最终 payload 及 FFmpeg 套件使用实际交付文件。loopback 测试使用真实 HTTP 协议和生产下载器，不访问远端。源级界面测试运行实际 WinForms 窗体，但通过测试服务控制下载成功、失败和取消。

RTX 20、Intel 和其他代际分类/界面验证是确定性输入测试，不是对应实体显卡上的 GPU 推理。实际联网端到端使用本机物理 RTX 5080。本记录不宣称完成所有显卡的渲染测试或所有时长的视频压力测试；运行时 AA 验收由单独记录说明。

初版测试夹具曾使用过长目录触发 Framework 4 的路径长度限制，目标安全回滚；交付测试随后改用新的短根 `p-*` 和 `f-*`。最初窗体测试缺少标准消息循环的问题已在测试框架内修复。失败记录保留用于审计，不计入通过结果。

本测试没有改写日常 AA、旧基线或 R6 交付。日常已验收 DLL 仍为 `855425D9AAF87ACF0CD3F5E76903DB19DEBB76268912EE8095AF8175591339E7`。
