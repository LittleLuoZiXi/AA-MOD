不支持的显卡或缺少组件时仍禁用 DLSS 并提示原因，保留用户的历史偏好而不执行增强。恢复为可用环境后，下次打开面板会恢复上次选择。开始前统计总时长不记忆，继续保持每次默认关闭，开启仍需确认。

本版不自动安装或下载 DLSS，也不修改 AA 本体。修改后的代码与安装包先本地验证，尚未上传 GitHub。

## 使用

保存剧情并关闭 AA，运行 V1.2.4 加壳安装 EXE，选择 AA 根目录。已有内录时确认覆盖升级；支持有效的 0.2.1、1.0.0、1.1.0、1.2.0、1.2.1、1.2.2、1.2.3 安装。默认不勾选 DLSS，此时仅安装内录，不检查显卡、不下载 DLSS 组件。FFmpeg 会自动检测，找不到时提示是否部署随包私有版本。

进入“剧情”，点击“入场”旁的“内录”，或按 F8/F9。选择输出目录和帧率；设置自动记住，首次输出目录为 Windows 视频文件夹。“开始前统计总时长”使用与帧率设置一致的原生状态按钮，每次打开均显示“关闭”，只影响本次任务，不保存为下次默认值。保持关闭时直接开始内录，不先完整预演；进度显示已生成秒数和实际耗时，不显示预计总时长或依赖总时长的百分比。

点击“关闭”按钮申请开启时，每次都先确认：“统计总时长需要完整的预演一次，会极大的拖慢内录的耗时时长，是否开启？”选择“是”才开启；“否”、关闭确认框、点击遮罩或 Esc 均保持关闭。按钮显示“开启”时再次点击即可关闭，重新打开设置仍为关闭。

只有开启并确认后，开始时才显示“正在计算视频总时长”：程序完整预演本次 AUTO 路线，此时不生成视频。计算完成后显示固定的“预计总时长 X.X 秒”，再从同一剧情快照重新播放并正式导出。“已生成”秒数持续增加，预计值保持不变；它是预计成品视频时长，不是剩余实际等待时间。

成品帧率由内录选项控制；AA 的原帧率上限设置结束后恢复。普通内录沿用 V1.2.2 的固定剧情时钟加速方式，逻辑与 PCM 以剧情时间推进，普通画面按固定 60 Hz 合成，标题和背景等待仍强制真实绘制。输出 FPS 不改变剧情时钟；速度和手动播放时长差异仍以具体剧情实测为准。

普通内录默认一遍完成，不先预演；若需要回退实时录制，可在配置的 Recording 段将 AcceleratedRecording 设为 false。预演回放、实时回退与加速模式沿用上一版实现。本版只增加自动更新，不重新宣称新的计时或速度验收结果。

开启统计时，预演记录原生时间步长，再重放同一时间表，通常需要播放两遍，实际耗时取决于电脑性能。预计帧数的末帧取整误差小于一帧；自然结束允许一秒内调度差异，预计值不回写，实际差异单独记录。录制按本机显示器分辨率输出 MP4；F10 在预演阶段取消，在正式录制阶段停止并保存已生成的视频。用户确认的 152 条缺语音属于 AA 既有状况，本轮忽略，不作为 MOD 验收阻断。

有分支的工程先标记 AUTO 默认选项。录制保留 AA 的默认选项、原生倒计时、退出动画和分支回调。遇到无 AUTO 默认项时显示“剧情中存在可选项，并且未标记 auto，故无法进行内录。”并停止：开启统计时在预演阶段发现，关闭统计时在录制过程中发现。开启统计时，AUTO 路线重复进入同一节点或预演达到配置时长/等待上限，也会在正式导出前停止并提示原因，不猜测分支。

安装和卸载仅处理本 MOD 收据中归属明确的文件。其他 MOD、源码工程、剧情、成品视频及用户修改过的文件保留。卸载入口为 `mods/AzureArchiveRecorder/卸载内录MOD.exe`。

## 实现与维护

- `src/Plugin.cs`：录制生命周期、工程快照编译、原生时间表生命周期、离屏相机、内部音频及停止恢复。
- `src/RecordingPreflight.cs`：仅开启统计总时长时，先按 AA 原生时钟预演完整 AUTO 路线；不启动编码器、不读取 GPU 图像，真实混音继续推进且仅临时静音。检查路线、快照哈希和上限后，退出旧播放器，从同一编译快照开始正式导出。
- `src/NativeCaptureTimeline.cs` / `RecordingNativeClock.cs`：原生帧步长、直接录制或已冻结时间轴重放、目标 FPS 采样和逐步独立 PCM。
- `src/NativeLiveCaptureTimeline.cs` / `NativeCompositeSchedule.cs` / `RecordingLiveClock.cs`：实际源间隔、固定 60 Hz 普通合成门控、双纹理保留最近完成画面及独立 PCM；输出 FPS 不改变合成调度。
- `src/RecordingControls.cs`：仅隐藏 MENU/AUTO 子树中的 UIWidget，刷新相关面板并恢复原状态；不关闭共享面板或剧情选项。
- `src/RecordingCameras.cs`：观察本帧实际渲染；完整自动合成复用，否则清空离屏目标并按 depth 补绘完整相机组合，让原生背景渲染回调解除标题等待；停止时移除跟踪。上一版验收状态见 `CONTINUE-V1.2.2.md`，原标题排查见 `V1.2.1-TITLE-HOTFIX.md`。
- `src/RecordingDurationPlan.cs`：预演结束后一次性 `Freeze(frames, fps)`；除新任务 `Reset()` 外预计总时长不可修改。完成数据独立保留实际帧数和 `durationDifferenceSeconds`。
- `src/RecordingChoices.cs`：在原生 AUTO 倒计时触发默认按钮时，用 `SelectionElement.OnSelect()` 代替依赖鼠标上下文的模拟按压，避免离屏模式下的 `MXButton.OnPress` 空引用；并保留倒计时完成后的受限补提交检查。AA 负责禁用按钮、退场动画和分支推进。
- `src/ChoiceProbe.cs`：仅 `--aa-recorder-choice-probe` 启用的诊断日志；不替代选项执行逻辑。
- `src/NativeRecorderUi*.cs`：原生风格设置、每次默认关闭的时长状态按钮与确认层、进度及教程；`DailyExportNaming.cs`：日期序号。
- `src/Encoder.cs` / `EncoderWorkQueue.cs`：FFmpeg 编码与封装，统一 FIFO 保留音视频顺序；限制 3 张等待图像，另允许 1 张正在写入的图像，PCM 独立按 12 秒字节量限额且包含正在写入的块。完成、故障和中止释放配额并唤醒等待；`GetQueueDiagnostics()` 记录容量等待、峰值及最终配额。区分输入/输出 FPS，以整数向上取整计算 `OutputFrameCount()`，异帧率时在首次编码前使用 FPS 滤镜；旧构造默认输入等于输出。仅成品成功后的临时文件清理采用容错，真实编码、封装或发布错误仍报失败。
- `src/FrameReadback.cs` 与实时录制时钟：记录 GPU 强制等待次数、累计及最大耗时，以及源间隔最大值、超过 100 ms/1 秒的次数；只读累计 scaled 时间、`unscaledDeltaTime-deltaTime` 正差及次数，并记录 `maximumDeltaTime`，帮助检验长帧时钟限制，不修改时钟参数、不逐源帧写日志。
- `bridge/` 及 DLSS 相关源码继承 V1.1，本次未改；本机不具备 RTX，未做 DLSS 测试。
- `packaging/build-release.ps1`：Obfuscar 混淆与压缩加密封装 MOD、安装器、卸载器；不保证不可逆向。构建依赖与复用冻结 runtime 见 `packaging/BUILD-V1.2.1.md`。

开发编译使用 PowerShell 7 执行 `build.ps1`，`-Install` 安装开发 DLL。正式交付必须使用保护构建脚本；不要将开发 DLL 当成加壳版本发布。
