# AzureArchive 内录 MOD V1.2.4

V1.2.4 增加自动更新。打开“内录”面板后，MOD 在后台检查适用于当前 AA 的新版本；同意更新后显示下载进度，支持暂停、继续和终止。文件安装完成后显示“内录MOD更新完成，AA即将重启”，点击唯一的 OK 按钮才重启 AA。

视频帧率、DLSS 开关与增强参数、输出文件夹继续自动保存，同一 AA 配置方案下跨工程和重启沿用。“提前统计总时长”每次默认关闭，不保存为下次默认值。

## 安装与使用

1. 保存工程并关闭 AA，运行发布页的“内录MOD1.2.4版本安装包.exe”，选择 AA 根目录；已有内录版本时按提示确认覆盖。
2. 进入“剧情”，点击“入场”旁的“内录”，也可使用 F8/F9 打开面板。
3. 选择成品帧率、输出目录及可用的增强设置，点击“开始内录”。未选择输出目录时使用 Windows“视频”文件夹。
4. 普通内录直接开始；只有确认开启“提前统计总时长”后才先完整预演一次。F10 可取消预演，或停止录制并保留已生成的视频。

录制使用本机显示器分辨率，导出 MP4。剧情分支须指定 AUTO 默认选项；没有默认项时给出明确提示并停止。录制期间显示进度面板，设置、计时和采样行为沿用已有实现。

DLSS 为可选功能。安装器默认不勾选 DLSS；自动更新不会下载或安装 DLSS 组件。不支持的显卡或缺少所需组件时，面板用红字说明并禁用对应增强功能，已保存的偏好仍保留。普通 MP4 内录可独立使用；FFmpeg 会自动检测，缺少时由安装器询问是否部署随包组件。

## 自动更新

有适用的新版本时显示“内录MOD有新版本，是否进行更新？”。选择不更新可以继续内录；同意后进入下载面板。下载完成并核对文件后再安装，安装过程中暂停录制入口，完成后由用户点击 OK 确认重启。

未保存的工程需要先保存再更新。配置文件、其他 MOD、剧情工程和成品视频保留；安装、更新和卸载仅处理归属明确的内录 MOD 文件。卸载入口为 `mods/AzureArchiveRecorder/卸载内录MOD.exe`。本 MOD 不修改 AA 本体。
