# 内录 MOD V1.2（1.2.0）

基于 V1.1 安装器修正基线；仅修复普通内录 AUTO 分支推进并增加 1.1.0 升级支持。

- 复现：原生 AUTO 协程已累计约 4 秒并结束，但离屏录制中的默认选项未被接受，播放器保持 HardLocked 与 hasSelection，最终仅被最长录制时长停止。
- 根因进一步验证：原生 `MXButton.OnPress` 在离屏模拟按压协程中触发空引用，默认选项回调未执行。仅对当前录制播放器的有效 AUTO 默认按钮，在模拟按压协程入口直接调用原生 `OnSelect`，普通播放和其他按钮不变。最终测试确认该调用栈不再出现。
- 兼容补提交：对当前录制器所属 SelectionManager 的 AUTO 协程按名称前缀挂接，在协程自然完成后校验倒计时、活动状态、默认索引、原始选项实例及按钮状态，必要时调用 AA 原生 OnSelect。已取消、已提交、被替换的选项与其他播放器不受影响。
- 不重写倒计时，不直接跳转剧情索引，不猜选第一项；保留原生禁用按钮、退场动画和分支回调。
- 诊断选项 `--aa-recorder-choice-probe` 仅记录状态；正常运行不挂接这些测试日志补丁。固定视频时钟、音频、录制 UI 和 DLSS 逻辑沿用 V1.1。
- 安装器、MOD loader、EXE shell 版本升为 1.2.0。有效的 1.1.0 收据纳入安全升级；旧收据仅允许对应旧版文件范围，继续按哈希决定清理归属。
- 安装器默认不勾选 DLSS，本次测试和部署不选 DLSS。

复现实例、回归与最终加壳验证见 V1.2-VERIFICATION.md。
