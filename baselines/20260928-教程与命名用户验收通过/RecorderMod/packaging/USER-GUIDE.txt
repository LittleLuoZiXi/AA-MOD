AzureArchive 内录 MOD 0.2.1 R5 RTX 集成版

安装 EXE 已内置 FFmpeg / ffprobe，安装时无需联网下载或手动安装编码器。
确认安装后，优先检查配置路径、PATH、AA 附近及常见 FFmpeg 安装位置，并实际试编码。
自动配置可用路径；没找到时使用本 MOD 私有目录 runtime\ffmpeg 内的便携版本。
没找到可用版本时，会弹出“安装内置 FFmpeg”确认框；选择安装才继续，选择取消则终止本次安装且不改文件。
已找到可用版本时不弹这个确认框。
内置版本总会保留作后备；AA 目录搬迁或原工具被删除后可自动回退。
不修改系统 PATH，不覆盖或卸载外部 FFmpeg。内置组件按清单随本 MOD 卸载。

修复部分电脑的 Test.OnDestroy 缺失导致整个 MOD 加载失败、内录按钮不出现的问题。
此回调与 OnReady 按实际存在情况挂接；协程类型不再依赖固定的生成编号。
已有 0.2.1 用户关闭 AA 后，运行新安装包并选择“覆盖重新安装”即可更新。
加载成功的日志包含：Recorder ready (0.2.1 R5 RTX integration; bounded cancellation and progress)。

安装：关闭 AA，将安装 EXE 放在 AzureArchive.exe 旁，双击后安装。
安装器也可浏览选择其他 AzureArchive 1.0 fix4 根目录。
安装位置为 mods\AzureArchiveRecorder；自动为当前 MOD profile 启用。
安装前检测 BepInEx / MOD 管理器、.NET 运行时、FFmpeg 和可选增强组件。
缺少依赖时列出缺失项目及影响，询问是否继续安装，默认取消。
已经安装时显示已安装版本，询问是否覆盖重新安装，默认取消；其他配置保留，仅修复必要的 FFmpegPath。
选择取消不会写入文件。其他必需框架和可选 DLSS 组件仍按检测结果提示。
出错会弹框，回滚本次安装改动，并以错误码终止程序。

使用：启动 AA，在“剧情 → 入场”旁点击“内录”。
可按次选择输出文件夹；未选择时使用 Windows 视频文件夹。
录制期间只显示进度，支持加速逐帧导出和“停止并保存”。
普通 MP4 内录不要求 NVIDIA。上游未适配的显卡以红色提示暂不支持增强。
RTX 5080 已进行实际超分、补帧及神经渲染测试，具体阶段和版本以随附验证报告为准。未测试的其他型号不作实测保证。
FFmpegPath 由安装器写入 profiles\当前配置\configs\azurearchive.recorder.cfg。
新配置默认使用内置 FFmpeg，普通 MP4 不依赖 DLSS5Tool 安装目录。
增强辅助环境已包含，无需单独安装 Python；仍需 DLSS5Tool 原有 NVIDIA 组件。
在 [DLSS] ToolDirectory 设置完整工具根目录；50 系须使用 SHA-256 匹配的 50 系 nvngx_dlssnr.dll。
增强界面显示实际处理进度。取消先通知上游，10 秒仍未结束则终止本任务的全部子进程，始终保留普通 MP4。
[DLSS] TimeoutMinutes 默认为 120 分钟，可设 1–1440；达到总时限同样结束本任务并保留原片。
每次任务保留增强结果、中文日志、原生 GPU 日志和进程结束原因。短暂读取占用进度文件不会再中断推理。

卸载：先关闭 AA，再双击本文件夹中的“卸载内录MOD.exe”。
按受限文件清单与哈希删除安装文件，清理内录配置及 profile 中的内录启用项。
已识别且未修改的旧版内录 DLL/manifest 也会清理。
其他 MOD、原剧情、已导出视频、开发用 RecorderMod 源码目录均不删除。
被用户修改或自行放入的未知文件会保留；不会递归删除整个 mods 目录。
拒绝目录联接、符号链接和越界清单，避免卸载波及其他位置。

保护：MOD 核心经过符号/字符串混淆、压缩加密封装和主程序校验。
每次正式打包都会对安装 EXE、卸载 EXE 执行混淆与加密加壳，校验后在内存中加载执行。
FFmpeg 等第三方程序保持原始文件及许可证，不冒称为本 MOD 的私有源码。
只支持此 AzureArchive 1.0 fix4 主程序，更新本体后可能需要更新此 MOD。
发布包不含本 MOD 的 C# / Python 源码、调试符号和混淆映射。
本地代码始终存在被逆向的可能，这不是不可破解或 DRM 保证。
