基线：**AzureArchiveRecorder 0.2.1 R4**，导出日期 2026-09-28。本包需完整解压，不要直接在 ZIP 内运行。

| 路径 | 内容 |
| --- | --- |
| `安装程序` | 最新加壳正式安装 EXE 与未加壳开发安装 EXE；一次只装一种，可覆盖切换 |
| `源码工程/RecorderMod` | 完整 MOD 源码、构建与测试脚本、混淆工具、已冻结 Python 增强程序、私有 FFmpeg 及许可 |
| `依赖与上游/DLSS5Tool-v2.3.3-win64` | 现有便携工具及完整 `_internal`，不含原电脑用户设置/任务队列/导出历史 |
| `依赖与上游/DLSS5Tool-source` | 上游源码快照与许可，不含 `.git`、缓存；原生组件重建的 SDK 前提见测试计划 |
| `验证记录` | 原机 R4 测试日志、制品保护证据、交接时的安装器哈希 |

给下一台电脑的 Codex 的启动指令可以直接使用：

> 请读取此文件、AGENTS.md、源码工程/RecorderMod/HANDOFF.md 和 DLSS-RTX-TEST-PLAN.md，接手 AA 录制 MOD。先核验交接包与该机的 AA/GPU/驱动/依赖，在隔离的 AA 测试副本安装并验证普通 MP4，再逐项实测 DLSS 超分、补帧、神经渲染并修复。每项保留真实日志和视频指标，不把未测项目标为通过，正式发布仍必须加壳。不要修改 AA 本体、用户剧情或删除其他 MOD。

## 新电脑上的准备

1. 用 PowerShell 7 运行 `pwsh -NoProfile -File .\校验交接包.ps1`。校验会读取所有大文件，需稍等；不会安装或运行 GPU 推理。
2. 准备完整 AA 1.0 fix4、BepInEx 6 IL2CPP、ModTheAzureArchive 和 AA 的 `dotnet`、`BepInEx/interop`。**包内不含 AA 游戏本体**。已构建安装器锁定本体 SHA-256：`260FC3ECC5F38DAB5230BA624A52E495708D861196DDA72486C1250760FE6EFF`；不同本体会报错，不要绕过校验硬装。
3. 把需要的一个安装 EXE 复制到 AA 根目录双击。缺有效 FFmpeg 时选择安装内置版本；重复安装需确认覆盖。基础框架缺失仍需补齐，缺增强依赖不影响普通 MP4 按钮。
4. 在当前 MOD 配置启用 0.2.1，重启 AA。先录普通 MP4；入口在“剧情 → 入场”旁，F8 为备用入口。
5. 把附带 DLSS 工具解压到固定位置。关闭 AA，编辑 `profiles/<ActiveProfile.txt 指定的配置>/configs/azurearchive.recorder.cfg`，将 `[DLSS] ToolDirectory` 指向该工具**根目录**，不要指向 ffmpeg.exe。UI 当前没有工具路径选择框。实际显卡/配置详情见交接文档。

附带的 `nvngx_dlssnr.dll` 是 **RTX 40 系**版本。RTX 30/50 系需要按固定上游附件下载安装各自运行库并核验哈希；20 系或没有配置的型号按要求显示红色“暂不支持”。NVIDIA 驱动由目标电脑提供。本包不是全系列离线运行库合集。

## 继续修改和构建

将 `源码工程/RecorderMod` 整个目录放到 AA 测试副本根目录，与 AzureArchive.exe 同级。使用 PowerShell 7；安装器还使用 Windows 的 .NET Framework 4.x 编译器。

```powershell
# 调试安装器：不加壳，MOD 有嵌入调试信息
pwsh -NoProfile -File .\RecorderMod\packaging\build-development-installer.ps1
# 正式安装器：保护 MOD、安装器和卸载器
pwsh -NoProfile -File .\RecorderMod\packaging\build-release.ps1
```

包中已有冻结增强运行时，修改 C# 后可以复用。修改 Python 桥接必须用 Python 3.12 重建 `.venv`，运行 setup-dlss.ps1、安装 PyInstaller 6.22.0，再运行 build-enhancer.ps1，最后重新构建安装器。不要复制原机器 `.venv`；依赖安装需要网络。详细命令、测试编译方法、音频/回读不能破坏的细节都在 HANDOFF.md。

本包开发 EXE 包含未加壳的 MOD/安装/卸载程序。第三方二进制和冻结 Python 的形式各自保留。加壳用于提高逆向成本，不是“无法破解”的保证；源码交接包仅用于自己的开发协作。

## 已验证与待验证

原机无 NVIDIA 显卡。正式 R4 已通过 37 项安装/依赖/FFmpeg/保护检查，真实普通视频为 3120×2080、60 fps、19.2 秒、有声 H.264/AAC，已检查完整解码与窗口恢复。任务该次耗时约 25.11 秒，不能承诺所有剧情快于实时。开发版与正式版切换结果见验证记录。

RTX 超分、补帧、神经渲染、NVENC 均待新电脑实测。FFmpeg 内置只解决普通录制依赖；增强仍依赖完整 DLSS 工具。工具及 FFmpeg 的许可证、出处保留在各自目录；FFmpeg 目录不声称包含完整的对应第三方源代码集合。
