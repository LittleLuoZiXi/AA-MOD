## 尚未验证

按用户要求，**没有在本机运行 NVIDIA 超分、DLSSG 补帧、神经渲染测试**。型号识别、配置/哈希匹配与接口检查不能代替 NVIDIA 实机验收。运行库首次联网自动下载也未在本机触发（本机显卡不适配）。普通视频编码的 Intel QSV 已实测；NVENC / AMD AMF 的硬件编码尚未实机覆盖。

本次实录是短篇、原生资源、无分支样例；复杂多分支、交互式剧情指令、长时间录制、第三方 MOD/特殊相机和自定义资源需要进一步实机覆盖。第三方自定义时钟也可能需要专门适配。当前分支策略沿用原生 AUTO，要求创作者为需要无人值守的分支设置默认选项。

测试日志和截图保留在 `RecorderMod/test-output`，逐次录制素材与元数据位于 `Recordings`，没有删除失败现场；独立 Python 环境用于实际增强桥接。正式 ZIP 不包含测试视频、运行时目录或 Python 环境。
