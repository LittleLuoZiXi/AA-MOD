# AA 内录 MOD 基线代码

本目录按日期保存三个独立代码快照，保留各自源码、构建和测试脚本、第三方许可及教程所需素材。

| 日期 | 版本 | 内容 | 详细说明 |
| --- | --- | --- | --- |
| 2026-09-28 | 0.2.1 教程与命名验收版 | 六页新手教程、日期序号命名，沿用此前 DLSS 总开关 | [版本说明](20260928-教程与命名用户验收通过/版本说明.md) |

每个目录的 RecorderMod 是该基线的原样项目源码，source-manifest.json 固定文件大小和 SHA-256。

这里只归档代码及所需素材，不包含 AA 游戏本体、安装 EXE、编译 DLL、FFmpeg/DLSS 运行库、Python 环境或测试导出视频。构建需要各版本文档中说明的本地依赖；不能将此代码归档当作完整安装包。

第三方代码与美术素材的许可、来源说明保留在原项目相应目录。历史文档中记录的本机路径属于当时开发环境，使用时应按本地目录配置。
