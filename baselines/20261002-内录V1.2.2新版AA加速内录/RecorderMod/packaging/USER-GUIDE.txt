AzureArchive 内录 V1.2.1（1.2.1）

提供加壳与未加壳两种合并安装 EXE，选择一份即可。两版功能一致，可通过覆盖确认切换。
DLSS 默认不勾选；未勾选时仅安装内录 MOD，不检测显卡，也不下载或改动 DLSS 组件。
勾选 DLSS 后才检查显卡；支持的显卡可以再次取消勾选。保留勾选时，先安装内录，再从固定 GitHub 发布下载并安装对应 DLSS 组件。
安装 EXE 不内嵌 NVIDIA DLSS 原生库；内录桥接环境与普通录制所需的 FFmpeg 仍包含在安装包内。
两版都有内录卸载 EXE；完成 DLSS 安装后另有独立的 DLSS 卸载 EXE。

安装前保存剧情并关闭目标 AA。双击 EXE，选择包含 AzureArchive.exe 的 AA 1.0 fix4 根目录。
向导会先列出内录、加载框架和 FFmpeg 的状态；DLSS 初始显示“未选择”，勾选后才检查显卡及对应组件。
检查完成后点击“开始安装内录”。缺少必需加载框架仍会说明影响并确认，不代替安装 AA 本体或框架。
重复安装和升级需确认覆盖；保留其他 MOD、剧情、导出视频、录制配置、教程已看状态和日期序号。
支持从有效的 0.2.1、1.0.0、1.1.0 和 1.2.0 安装升级；所有已启用此内录 MOD 的 profile 都迁移到 1.2.1，未启用此 MOD 的其他 profile 保持原样。

FFmpeg 规则不变：先实际验证配置路径、PATH、AA 附近和常见位置的编码器。
已有可用编码器时继续使用；找不到时显示“安装内置 FFmpeg”确认，取消则不写入本次内录安装文件。
私有 FFmpeg/ffprobe 始终随内录保留作为后备；不修改系统 PATH、不覆盖或卸载外部编码器。

勾选 DLSS 时的显卡检查：
- 支持的 RTX 30/40/50 系：保留勾选或主动取消；保留时，内录完成后只下载共同组件和本机系列的固定压缩包，校验压缩包与 DLL 后安装。
- RTX 20 系：勾选时提示“暂时不支持20系”；确认后自动取消并禁用 DLSS 选项，随后仅安装内录，不强制退出向导。
- 非英伟达显卡：勾选时弹框说明不是英伟达（NVIDIA）显卡；确认后取消并禁用 DLSS，仍可正常安装内录。
- 其他不支持的英伟达系列：勾选时弹框说明该系列暂不支持；确认后取消并禁用 DLSS，仅安装内录。
- 不同系列多张 NVIDIA 卡或检测失败：弹框说明无法确认/选择运行库，确认后禁用本窗口 DLSS 选项，仅安装内录。
- 不支持提示确认后，更换 AA 目录或重新检测目录不会自动恢复 DLSS 勾选。
- 已有完整且经过校验的独立补充包可直接使用，不重复下载，也不删除原来其他系列的文件。

下载时显示进度、暂停/恢复与取消按钮。进度条上方每隔四秒轮换：
“请确保网络可以连接至github。” / “如遇下载卡顿需暂停后排查网络。”
暂停保留本次下载进度；恢复时尝试断点续传，服务器不支持时会从头下载，不会将整包追加到半包后。
选择 DLSS 后，只有下载、校验和安装全部完成，“继续”才可点击；未选择时，内录本体完成即可继续。
取消或失败会清理本次下载暂存，保留已完成的内录本体和原有组件；可重试 DLSS 或退出安装。
下载失败不会把 DLSS 标记为可用，不会自动替换固定校验值。
建议使用较短的 AA 路径；此版本不宣称支持任意超长 Windows 路径。

DLSS 组件位于 mods\AzureArchiveDLSS\runtime，根据显卡保存到对应 rtx30/rtx40/rtx50 文件夹。
内录自动发现该位置，无需手工修改 ToolDirectory；保留旧外部工具路径的兼容读取。
不安装或修改 NVIDIA 驱动，不启动上游完整界面，不安装其他系列、模型包或系统 CUDA Toolkit。

使用：启动 AA，在“剧情 → 入场”旁点击“内录”，也可用 F8/F9 打开，F10 停止并保存。
“开始前统计总时长”使用与帧率设置一致的原生状态按钮，每次打开内录设置均默认显示“关闭”，只影响本次任务，不保存为下次默认值。
保持关闭时直接开始录制，不先完整预演；进度显示已生成秒数和实际耗时，不显示预计总时长或依赖总时长的百分比。
每次点击“关闭”按钮申请开启时，会先确认：“统计总时长需要完整的预演一次，会极大的拖慢内录的耗时时长，是否开启？”
选择“是”才开启；“否”、关闭确认框、点击遮罩或 Esc 都保持关闭。按钮显示“开启”时再次点击即可关闭；重新打开设置仍为关闭。
开启并确认后，先按 AA 原生节奏完整预演 AUTO 路线并固定预计总时长，此时不生成视频，再按记录的时间表从头录制。
只有开启统计才需要“预演 + 正式录制”两遍，等待时间会明显增加，具体耗时取决于电脑性能。预计总时长是预计成片时长，不是剩余实际等待时间；自然结束保留完整画面和音频，不裁剪剧情凑预计值。
普通内录默认采用固定剧情时钟加速处理，视频和音频按剧情时间输出；30/60 FPS 等只决定成品采样密度，AA 的原帧率上限设置保持不变。开启统计时仍完整原生预演并按时间表回放。音频独立连续采集，不随重复画面重复写入。
本机新版 AA 的同一完整剧情测试：自然 AUTO 约 420.13 秒；30 FPS 成片 421.33 秒、全流程 226.24 秒；60 FPS 成片 421.32 秒、全流程 364.67 秒。速度依电脑和剧情而异，不能保证所有剧情与手动播放精确同长。
如需回退实时录制，可在当前 profile 的 configs\\azurearchive.recorder.cfg 的 [Recording] 中设置 AcceleratedRecording = false，下次开始录制生效。
录制期间只显示进度；MENU/AUTO 控件不会写入成片。F10 在可选预演阶段取消，在正式录制阶段停止并保存。
第一次进入设置显示六页阿罗娜教程，可点高亮目标、上一步/下一步，或随时点击右上角跳过；背景操作锁定。
设置中的“新手教程”可随时回看，已看状态按 profile 保存。
输出可按次选择文件夹，默认 Windows 视频文件夹。名称为 yyyyMMdd-序号.mp4，同日跨重启递增，次日从 1 开始。
增强时保留“原始视频”子目录中的原片，原片和增强成片使用同一个日期序号。

安装器是否选择 DLSS 与内录设置中的 DLSS 总开关分开；安装组件不会自动打开增强。
每次打开内录设置，DLSS 默认关闭。
缺少本机所需组件或运行库不匹配时，总开关与超分、补帧、神经渲染全部灰色不可选，红字显示：
“缺少DLSS组件，相关DLSS功能不可用。”
设置打开期间移走组件也会重新禁用，已保存的参数不能绕过检查。恢复组件后仍需主动开启总开关。
普通 MP4 不依赖 DLSS，也不要求 NVIDIA 显卡。录制阶段不再自动下载 DLSS 文件。
超分和补帧倍率、神经渲染效果以实际硬件与素材为准；3/4 倍补帧为实验路径，神经渲染可能改变二次元画风。
增强取消和超时保留普通原片；[DLSS] TimeoutMinutes 默认 120 分钟，可设 1–1440。

卸载前关闭 AA：
- 内录：mods\AzureArchiveRecorder\卸载内录MOD.exe
- DLSS：mods\AzureArchiveDLSS\卸载DLSS补充MOD.exe
两个产品独立卸载，不互相删除。按受限清单和哈希清理自有安装文件；配置、教程状态、导出序号、剧情、视频、其他 MOD 与修改过或未知文件保留。
内录卸载会移除各 profile 中本 MOD 的启用项；不会递归删除整个 mods 目录。

加壳版保护 MOD 核心、合并安装 EXE 和两个卸载 EXE；采用混淆、压缩加密与内存加载。
未加壳版的上述程序保留可读结构。第三方 FFmpeg/NVIDIA 原生文件保持原始字节与原始许可。
本地保护不能保证不可逆向。来源、固定摘要和原始许可随组件保留。
