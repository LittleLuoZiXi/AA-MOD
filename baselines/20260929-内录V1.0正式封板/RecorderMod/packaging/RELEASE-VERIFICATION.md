## FFmpeg 安装行为

安装 EXE 包含本机已验证的 Gyan FFmpeg/ffprobe 7.1.1 full 构建，无需安装时联网。优先检测当前配置、PATH、AA 附近及常见安装位置，不遍历全盘；通过版本与 CPU libx264/AAC MP4 试编码判断可用性，不只看文件名。

未找到可用工具时，先弹“安装内置 FFmpeg”，默认取消。确认后才写文件，取消则整个安装返回取消状态，无任何文件变更。已有有效外部或内置 FFmpeg 不重复询问。内置后备部署于 `mods/AzureArchiveRecorder/runtime/ffmpeg`，不修改系统 PATH 或外部工具；安装器只在必要时修改 `[Recording] FFmpegPath`，其他配置保留。运行时发现旧路径消失，会改用当前 AA 目录内置版本。

原始 FFmpeg 二进制未修改，GPL 许可证、原构建 README、依赖版本、构建配置与来源记录在 `runtime/ffmpeg`。来源与本地 SHA 记录不冒称上游独立签名验证；目录不声称包含完整依赖源码包。首次尝试获取更小构建遇到本机 DNS 失败，最终采用已在本机实际录制验证过的现有完整构建。

## 每次发布强制保护

`build-release.ps1` 已移除 `SkipObfuscate`。正常构建重新保护 MOD 核心；`-InstallerOnly` 复用核心时同样检查其 `RecorderLoader` / `recorder.payload` 外壳结构，拒绝明文 RecorderPlugin。每次都会重新生成并保护安装、卸载 EXE：Obfuscar 私有符号/字符串混淆，GZip 压缩，AES-256 加密，外层校验解密核心 SHA256 后以内存 `Assembly.Load(byte[])` 调用入口。解密核心不落地，外层仅有 `aa.encrypted-core` 资源；解密材料和开发中间文件仅留在本地开发目录，不进入发布负载。

卸载器从壳传入的实际 EXE 位置判断路径，保留原来的受限清单/哈希删除与辅助进程机制。临时辅助 EXE按原逻辑登记重启清理，不宣称立即删除自身。第三方 FFmpeg 保持原版；本 MOD 的保护不能保证不可逆向。
