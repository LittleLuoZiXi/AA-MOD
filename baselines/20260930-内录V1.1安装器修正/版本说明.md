# 内录 MOD V1.1：DLSS 改为主动选择安装

版本：**1.1.0**。基线日期：**2026-09-30**。适用本体：AA 1.0 fix4。对照版本：[V1.0](../20260929-内录V1.0正式封板/版本说明.md)。

此版解决安装器默认勾选 DLSS 且无法取消的问题，并统一内录、安装器与卸载程序的版本标识。该快照完成技术验证；不把此前教程版的人工验收等同于 V1.1 已经人工验收。

## 安装操作的变化

| 操作或情况 | V1.1 的结果 |
| --- | --- |
| 首次打开安装器 | “安装 DLSS 组件（可选）”默认不勾选，显卡状态显示“勾选 DLSS 后检测” |
| 保持未勾选并开始安装 | 仅安装内录，不启动显卡检测、DLSS 下载或组件修改；已有 DLSS 保留 |
| 主动勾选，显卡支持 | 检测显卡和对应组件；开始安装前可以再次取消勾选 |
| 主动勾选，非英伟达显卡 | 弹框说明不是英伟达显卡；确认后自动取消并禁用本窗口的 DLSS 选择 |
| 主动勾选，不支持的英伟达系列 | 弹框说明该系列不支持；确认后取消并禁用 DLSS，仅安装内录 |
| RTX 20 系 | 勾选时提示“暂时不支持20系”，确认后仅安装内录；不再使用 V1.0 的后续退出流程 |
| 显卡检测失败或无法安全选择多卡系列 | 说明具体原因，确认后禁用本窗口的 DLSS 选择，保留普通内录安装 |
| 支持显卡且保持勾选 | 先安装内录，再安装 DLSS；完整本地组件直接复用，缺少时仍使用固定 GitHub 附件及校验值 |

拒绝 DLSS 后，重新检查 AA 目录也不会自动恢复勾选。选择检测和安装进行时暂时锁定输入，避免中途改变安装内容。

## 本版修复的边界问题

- 显卡支持但 AA 目录检查失败时，不再把目录错误当作显卡不支持。安装按钮保持不可用，修正目录后可以重新检测；仍允许取消 DLSS 选择。
- 取消勾选时同时更新组件列表、选项旁说明和底部状态，避免画面仍显示“已选择 DLSS”。
- 下载开始后，提示明确说明选择已锁定，应使用暂停或取消下载按钮；不会继续承诺可以取消勾选。
- 未选择 DLSS 时，内录完成即可继续；已选择时，下载、校验和组件安装全部完成后才开放继续按钮。
- 现有组件校验成功也不会导致安装器自动勾选 DLSS。

## 版本与升级

内录产品版本升为 `1.1.0`，安装器与相关程序集版本为 `1.1.0.0`。有效的 `0.2.1`、`1.0.0` 安装可升级，当前版本可重装；旧清单的文件范围按其自身版本校验，避免越界处理其他文件。

升级保留配置、教程已看状态、导出日期序号、已有视频和其他 MOD。加壳与未加壳版本可在覆盖确认后切换。内录与 DLSS 仍分别拥有卸载 EXE 和文件清单；**DLSS 独立产品的清单版本继续为 `1.0.0`**，不随内录版本一起替换。

## 保持的功能

六页教程及角色素材、日期序号命名、FFmpeg 发现与内置安装规则、固定附件下载与校验规则、暂停/恢复/取消机制、独立卸载与文件保留规则继续沿用。运行时缺组件仍会禁用 DLSS 总开关、超分、补帧与神经渲染，并显示红字“缺少DLSS组件，相关DLSS功能不可用。”；普通录制照常可用。

## 验证结果与范围

- 33 项安装核心、24 项最终界面、10 项安装内容与卸载检查通过，共 **67 项不同检查**；后续重复结构复验不重复计数。
- 两版共四个真实卸载 EXE 通过；最终两版安装器的默认仅内录、勾选复用本地组件、勾选后再取消三轮流程通过，原有 26 项 DLSS 文件及清单保持一致。
- 最终加壳 MOD 通过 25 条原生界面断言、201 个部署文件摘要检查。缺少组件时，直接调用增强按钮监听也不能执行增强。
- 普通成片为 2560×1440、H.264、30 fps、491 帧；AAC 48 kHz 双声道，完整音视频解码通过。视频和音频时长分别为 16.366667 秒和 16.366000 秒。
- 本轮没有重复实际联网下载、FFmpeg 专项或 GPU 增强测试。物理显卡仅 RTX 5080；其他显卡的拒绝分支为明确模拟，不能理解为这些实体显卡已经实测。
