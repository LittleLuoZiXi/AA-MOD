## 目录与使用

每个 `baselines/<日期与名称>/` 目录包含：

- `RecorderMod/`：对应基线的完整源码、构建/测试脚本、许可和所需教程素材。
- `版本说明.md`：功能变化、主要文件、验证结论和未覆盖范围。
- `文件变更清单.md`、`changes.json`：与指定前一基线逐文件比较的结果。
- `source-manifest.json`：归档源文件的大小与 SHA-256，便于核对原始快照。

此分支提供源码归档；V1.2.4新增自动更新，V1.2.5用于无功能变更的更新验收。正式测试起点保持V1.2.4；在线文件和更新清单分别发布，用户端完整更新流程待验收。可在仓库 Releases 下载发行附件，旧版本宿主要求见各自说明。AA 本体、安装 EXE、编译 DLL、FFmpeg/DLSS 运行库、Python 虚拟环境及测试输出不随归档上传。构建需要按对应版本文档准备依赖；源码归档本身不能代替安装包。

第三方代码、美术素材的来源与许可说明保留在各基线项目内。历史文档中的绝对路径是当时的开发环境记录，应改用自己的实际目录。

## 分支约定

内录代码和版本说明保留在 `mods/recorder`，不合并到 `master`、`main` 或仓库默认主分支。后续其他 MOD 应创建独立分支，例如 `mods/<类型>`，避免混用代码和发布说明。未经明确要求，不自动合并不同 MOD 的分支或覆盖历史基线。
